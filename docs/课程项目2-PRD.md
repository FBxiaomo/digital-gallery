## 1. 项目背景与基线（V1 原型）

「数码图鉴」为团队自建的纯静态消费数码参数知识库，V1 原型自 2026-05 上线并持续迭代至 Beta 0.60（2026-11-03），已部署于自定义域名与 GitHub Pages。

V1 基线能力盘点（2026-11-03 审计）：

| 项 | 现状 |
| --- | --- |
| 数据规模 | 手机 66 款、处理器 139 款、充电器 35 款、充电宝 20 款（测试版口径） |
| 核心功能 | 分类浏览、品牌/价格/关键参数筛选、最多 4 机对比与差异高亮、搜索（中英文/拼音/别名）、性能评分多方案、主题切换、彩蛋 |
| 数据分析 | 独立 analysis.html：按分类与指标查看样本数、中位数、分布、排行，支持筛选链接分享 |
| 工程设施 | 双版本工作流（b测试版先行 → 本地验证 → 手动同步 a正式版 → 部署）、自动化检查工具 `node tools/check-project.cjs`、SCHEMA/CONTRIBUTING/SDD 文档规范 |
| 已知欠账 | ① 15 项设备实图缺口（测试版口径，正式版 17 项）；② 分析页指标与交互待打磨；③ 正式版与测试版存在待同步项；④ 系统测试与验收文档缺失 |

**本课程项目（项目二）定位为：在 V1 基线之上完成 V2.0 优化完善迭代**，周期 9 个工作日（2026-11-03 ~ 2026-11-13），最后一天为项目验收。V1 历史仅作为基线与前期调研依据，本课程考核范围内的增量工作以迭代计划与每日提交记录为准。

## 2. 迭代目标与非目标

**目标：**
1. 资源完整性：设备实图缺口清零，图片路径与缓存版本规范统一。
2. 数据质量：充电器、处理器数据核对与扩充，缺失数据显式标注、不编造。
3. 分析深度：数据分析页指标、分布与排行完善，统计口径可解释。
4. 体验与工程质量：性能、图片缓存、可访问性、移动端适配达标；系统测试与验收文档齐备。
5. 发布闭环：正式版同步上线，交付项目报告、用户手册与答辩材料。

**非目标：**
- 不引入构建工具与后端服务，保持纯静态架构。
- 不新增设备大类（维持手机/处理器/充电器/充电宝四类）。
- 不做用户账号、评论等社区功能。

## 3. 用户与使用场景

| 用户 | 场景 |
| --- | --- |
| 数码爱好者/购机用户 | 按品牌、价格、关键参数筛选并对比候选机型与充电设备 |
| 参数党/评测读者 | 查处理器性能评分多方案口径，核对跑分来源与估算标记 |
| 数据研究者 | 用分析页查看品类样本数、中位数、分布与排行，分享筛选链接 |

## 5. 数据与技术规范

- 架构：纯 HTML/CSS/JS 单页 + `db/` 目录 JS 数据文件，无构建步骤；图鉴主逻辑内联于 index.html，分析页独立 analysis.html。
- 数据规范见 `SCHEMA.md`；修改工作流与代码约束见 `CONTRIBUTING.md`；验收补充见 `SDD.md`。
- 检查命令：`node tools/check-project.cjs`；静态检查通过不代表浏览器验收通过，交互修改按 SDD 验收。

## 6. 里程碑与验收

9 个工作日划分为：规划（D1）→ 冲刺一·资源与数据（D2–D4）→ 冲刺二·功能与体验（D5–D6）→ 系统测试（D7）→ 发布准备（D8）→ 验收（D9）。逐日任务、交付物与验收标准见《课程项目2-迭代计划》。

验收标准：
1. 图片缺口清零且检查工具全量通过；
2. PRD 需求清单 P0 全部完成、P1 完成 ≥80%；
3. 测试用例执行记录与 SDD 验收清单逐项结论可查；
4. 正式版上线且与测试版发布范围一致；
5. 答辩演示覆盖筛选、对比、分析页三类核心场景。

## 7. 风险与应对

| 风险 | 影响 | 应对 |
| --- | --- | --- |
| 13 项 P1 实图依赖外部素材搜集 | 冲刺一延期 | D4 设缓冲日；搜不到的型号按交接计划记录结论、不强行配图 |
| 跑分/规格来源不可核实 | 数据可信度 | 仅录官网或可信榜单可证数据，缺失显式标注，不编造 |
| 正式版同步范围误操作 | 线上事故 | 按发布范围手动同步，同步前跑检查工具并本地验证 |
| 测试与文档时间被开发挤占 | 验收材料不全 | D7 冻结新功能，仅修缺陷 |
